# Nimble Storage

> HPE Nimble Storage is an enterprise flash and adaptive-flash storage platform (acquired by Hewlett Packard Enterprise in 2017, now part of the HPE Alletra 6000 line). NimbleOS exposes a REST API for programmatic management of arrays, volumes, snapshots, and data protection, served per-array at https://<array>:5392/v1/ with session-token (X-Auth-Token) authentication. First-party Python, Go, and Ansible client libraries are published by HPE Nimble Storage DCS.

## APIs
- [NimbleOS REST API Reference](https://infosight.hpe.com/InfoSight/media/cms/active/public/pubs_REST_API_Reference_NOS_51x.whz/jun1455055569904.html): Object-set REST API (volumes, snapshots, pools, initiator groups, protection templates) served on each array at :5392/v1.

## SDKs
- [Python SDK (nimble-sdk)](https://pypi.org/project/nimble-sdk/): pip install nimble-sdk — source github.com/hpe-storage/nimble-python-sdk.
- [Go SDK](https://pkg.go.dev/github.com/hpe-storage/nimble-golang-sdk): go get github.com/hpe-storage/nimble-golang-sdk.
- [Ansible Collection (hpe.nimble)](https://galaxy.ansible.com/hpe/nimble): ansible-galaxy collection install hpe.nimble.

## Repos
- [NimbleStorage on GitHub](https://github.com/NimbleStorage): Automation and container examples, Nemo emulator, Puppet/Ansible modules.
- [hpe-storage on GitHub](https://github.com/hpe-storage): Python and Go SDKs and storage platform tooling.
